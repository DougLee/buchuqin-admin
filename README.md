# 不出寝食社 PC 综合管理后台

Vue 3 + TypeScript + Vite 实现的 MVP 管理后台，供平台运营、仓储、财务和管理员统一使用。

## 页面范围

- 经营总览：交易 KPI、近七日趋势、履约水位、楼栋排行和实时动态。
- 订单履约：订单状态、包裹、两段配送时效和异常操作。
- 售后退款：质量投诉、凭证和审核入口。
- 商品管理：SKU、校园售价、上下架状态，支持改价和调库存。
- 库存与批次：实际/锁定/可售库存、批次、有效期和低库存预警；一期将入库、盘点、拣货数据合并在此工作台呈现。
- 履约人员：楼长、全职/兼职配送员的状态与绩效。
- 校园组织：校园、仓库、楼栋、寝室和用户规模。
- 营销活动：优惠券预算、领取和核销数据；广告位作为后续配置项预留。
- 财务结算：底薪、提成、跨期调整和月结状态。
- 审计日志：关键状态、金额和权限变更留痕。

## 本地运行

```bash
# 先启动 API（项目根目录的另一个终端）
cd ../buchuqinshishe-api
pnpm start

# 再启动后台
cd ../buchuqinshishe-admin
pnpm install
pnpm dev
```

访问 <http://localhost:5190/>。开发环境会自动使用 `admin-mock` 登录并通过 Vite 代理访问 `http://localhost:3000/api/v1`。

## 验证

```bash
pnpm type-check
pnpm build
```

设计规范位于 `design-system/不出寝食社管理后台/MASTER.md`。
